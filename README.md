# 💻 Web IDE

**A lightweight and minimalistic HTML, CSS, and JavaScript editor and compiler.**  
*Built with Next.js, Tailwind CSS, and shadcn/ui for instant coding and live previews right in your browser.*

## ✨ Features

* **⚡ Live Editor:** Write clean HTML, CSS, and JavaScript with a distraction-free, minimalistic interface.
* **👁️ Instant Preview Pane:** Real-time rendering of your code output without manual page reloads.
* **🔄 Live Compile:** Automatic code compilation as you type for a seamless development workflow.
* **📐 Resizable Panes:** Flexibly adjust the workspace layout between code editors and the preview window to fit any screen size.

---

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Styling:** Tailwind CSS
* **UI Components:** shadcn/ui
* **Deployment:** Vercel
